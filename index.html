Cómo ejecutarlo

  1. Descargar y descomprimir el ZIP.
  2. Entrar a la carpeta SGN-Cesar.
  3. Ejecutar npm install.
  4. Ejecutar npm run dev.
  5. Abrir la dirección que aparece en la terminal (normalmente http://localhost:5173).

Requiere Node.js 20 o superior. El sistema incluye ventas, compras, inventario, clientes, proveedores y control de acceso por roles.
