Cómo instalarlo

  1. Descarga el archivo SGN-Setup.exe.
  2. Haz doble clic y sigue el asistente: Siguiente → Instalar.
  3. Abre el acceso directo SGN desde el escritorio.
  4. Ingresa con el usuario admin o el correo admin@sgn-negocios.com y la clave Admin123!.

Cambia la clave desde el módulo Usuarios la primera vez. Si desinstalas el programa, la base de datos se conserva para no perder información.

Qué incluye la versión 2.0

  • Ventas y facturación con numeración automática y cálculo de ISV.
  • Registro de clientes con RTN y datos de contacto.
  • Compras a proveedores con entrada al inventario.
  • Inventario con categorías, existencias y niveles mínimos de stock.
  • Usuarios y seguridad con roles de Administrador y Cajero.
  • Datos del negocio para personalizar las facturas.
