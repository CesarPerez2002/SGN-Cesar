Cómo instalarlo

  1. Descargar SGN-Setup.exe.
  2. Doble clic y seguir el asistente: Siguiente → Instalar.
  3. Abrir el ícono SGN desde el escritorio.
  4. Entrar con usuario admin o correo admin@sgn.local; clave Admin2026!.

Cambie la clave desde el módulo Usuarios la primera vez. Si desinstala el programa, la base de datos se conserva para no perder información.

Qué incluye la versión 1.1

  • Punto de Venta con factura numerada automáticamente.
  • Elección entre Comprador final y cliente guardado.
  • Carrito multiproducto, total automático y descuento de stock.
  • Compras con proveedor, factura y suma al inventario.
  • Menú según el documento del proyecto y acceso por usuario o correo.
