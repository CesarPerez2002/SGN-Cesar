Cómo instalarlo

  1. Descarga el archivo SGN-Setup.exe.
  2. Haz doble clic y sigue el asistente: Siguiente → Instalar.
  3. Abre el acceso directo SGN desde el escritorio.
  4. Ingresa con el usuario admin o el correo admin@sgn.local y la clave Admin2026!.

Cambia la clave desde el módulo Usuarios la primera vez. Si desinstalas el programa, la base de datos se conserva para no perder información.

Qué incluye la versión 1.1

  • Punto de Venta con factura numerada automáticamente.
  • Elección entre Comprador final y cliente guardado.
  • Carrito multiproducto, total automático y descuento de stock.
  • Compras con proveedor, factura y suma automática al inventario.
  • Menú según el documento del proyecto y acceso por usuario o correo.
